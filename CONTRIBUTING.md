# Contributing

Thanks for helping improve Awesome Gravity Defied!

## Adding a project

Open a pull request that adds a public GitHub repository related to the Gravity Defied motorcycle trial racing game.

- Choose the category that best matches the project's main purpose.
- Use the canonical repository URL, or link directly to the relevant directory when the game is part of a larger repository.
- Write a short, factual description in English and include the implementation language when useful.
- Check the README or source files to verify the features you describe. Include supporting links in the pull request description.
- Explain whether the project is a port, a remake, a tool, or an independent clone.
- For a fork, describe its distinct platform support, features, or maintenance work and acknowledge the upstream project.
- Mention material limitations, such as an experimental implementation or a documented build issue, when they affect the entry's usefulness.
- List each project once. Avoid unchanged forks, empty repositories, unrelated games, and download-only mirrors without a distinct purpose.

Use this format:

```markdown
- [owner/repository](https://github.com/owner/repository) - Short description of its purpose and distinguishing features. Language.
```

There is no minimum star count. Small tools and unusual experiments are welcome when their purpose is clear and relevant. Do not claim a project is official, actively maintained, or fully compatible without evidence.

## Corrections and cleanup

Issues and pull requests are welcome for broken links, moved repositories, inaccurate descriptions, missing upstream credits, and better categorization. Include a link to the relevant README, source file, or other primary evidence where possible.

An older project can still be useful. Do not remove an entry solely because it has not received recent commits; describe relevant limitations instead.
